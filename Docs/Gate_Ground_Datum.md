# Wenmingmen district test datum

The district map places the existing Wenmingmen Blueprint at UE XY `(180000, 121500) cm` on a diagnostic modern-context terrain sample. It uses the inventory's approximate `+332.5 cm` plaza-to-asset placement convention (rounded to `+333 cm` in the creation script). The Blueprint is kept at scale 1. This convention is asset grounding for a visual interface test, not a surveyed historical gate threshold or a late-Qing ground elevation.

`Data/Gate_Asset_Inventory.csv` records the asset envelope, canal-bed caveat and source manifest. `Maps/District_Test_Bounds.json` records that this XY sample is unrelated to accepted Wenmingmen metric bounds. The locked base Landscape is unchanged; `Urban_Grading`, `Road_Corridors` and `Drainage` are separable empty edit layers. Final placement requires the H2 local survey frame and a dated walking-surface Z tied to a named benchmark and datum. Re-evaluate the gate foundation and road threshold after those inputs arrive; do not move the terrain to conceal a discrepancy.
