# Visual Change Archive

This directory stores the visual completion record for project jobs.

For each implementation or fix job, add:

- `YYYY-MM-DD-<short-slug>.svg` — the human-readable before/after illustration.
- `YYYY-MM-DD-<short-slug>.md` — scope, behavior changes, tests, and the illustration link.

Then append the entry to `.claude/memory/visual-change-archive.md`. Existing entries are historical records and should not be rewritten; create a new dated entry for later work.
