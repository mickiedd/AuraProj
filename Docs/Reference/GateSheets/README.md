# Gate reference sheets

Canonical design reference sheets for the Guangzhou landmark gates. These are the
authoritative visual targets — any pass that modifies a gate model must be given
the matching sheet and must compare its renders against it.

Notes:

- The Wuxianmen and Zhengximen sheets were originally pasted into a codex session and
  only existed under the Windows temp directory; they were copied here so the
  references survive temp cleanup. The Wuxianmen sheet was independently re-supplied
  by the project owner on 2026-09-15 and matches the recovered copy exactly
  (same content, 1448x1086).
- Each sheet is a multi-panel design document: a three-quarter hero render plus
  front / side / rear elevations, a top view, a wireframe, and detail insets
  (roof tile, bracket / eave, gate arch, parapet or wall texture, gate door) and a
  materials reference strip. Use the insets as the per-detail targets and the
  materials strip as the palette target.
- Historical photographs are included on the Dadongmen and Guidemen sheets as
  supporting evidence for weathering, patina and vegetation.
