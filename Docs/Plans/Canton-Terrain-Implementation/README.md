# Canton terrain implementation — daily plans

This directory contains the independently executable version of the [Canton 1880–1900 UE5 Terrain 20-Day Plan](../Canton_1880_1900_UE5_Terrain_20_Day_Plan.md). The master plan owns the shared scope, milestone schedule, stop/go rules and minimum evidence packet. Each daily plan repeats its operational gate and links to a paired resource sheet that becomes the completion record.

Do not begin a downstream day merely because the previous calendar day ended. Its predecessor must be **Verified**, explicitly **Provisional** with isolated uncertainty, or **Blocked** with the downstream exception documented.
