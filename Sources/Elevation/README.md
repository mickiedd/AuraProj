# Elevation sources

No elevation raster is accepted or stored here yet. `ELEV-001` in `Data/Source_Register.csv` records Copernicus GLO-30 as a **modern surface model candidate**, which includes buildings and vegetation. This directory must receive a bare-earth or surveyed source with licence, checksum, accuracy, date and vertical datum before any historical ground height is derived. Do not use a gate mesh pivot as terrain zero.
