- 2026-09-25 — BP_Zhengdongmen roof courses made continuous, and the plaque corrected to traditional characters. The user asked for the tile courses to "cover each roof slope continuously" and to match the reference board, plus a fix to the plaque text. **The previous 2,998-tile pass had three defects that no size or count check can see.** First, the tiles were laid in **brick bond** — each row offset half a tile from the one above — which makes the roof read as a staggered scale pattern; a roof reads as its down-slope courses and courses only read if the ribs stay in line, so the stagger had to go. Second, each row was a **rectangle sized to that row's narrowest edge**, which leaves the trapezoid's widening area bare: the uncovered strip reached **0.420 m, wider than the 0.34 m hip ridge that would have hidden it**, and it formed a staircase down both hips. Third, the half-pitch stagger also exposed a strip at both side edges of every odd row. The fix is one run per pitch on a **fixed rib grid**, laid ridge to eave with 14% downslope overlap and **no row offset**, **clipped to the slope's own trapezoid and split at the parameter where the run first fits whole** so that every course edge — entry, split and trim — lies on the straight hip line; chording across either corner is exactly what left the wedges, and splitting makes the mesh exact instead. Runs enter where their clipped width reaches 3% of the pitch rather than at zero width, so no degenerate sliver is built, and a run that only just clears the drop threshold is no longer discarded — that off-by-one epsilon was itself worth **0.42 m of bare roof on the two narrow hip faces**. The cross-section became a real corrugation (a rounded rib 0.066 m proud over 46% of the pitch with a 0.020 m concave pan either side, 11 samples across) because that is what makes runs read as courses; the hip ridges widened 0.19 → 0.34 m to cap the trimmed ends, and are deliberately **seated on the hip line rather than lifted** — a +7 cm lift made the hip ridge the tallest part of the building and pushed the measured height to **1940 cm against the package's declared 1933 cm**. **The validator was the real gap and was rewritten**: it previously asked only whether a tile was wider than its pitch, which the staggered layout passed while leaving the hip wedges open. It now reconstructs the courses in slope-parametric space and proves coverage — **widest uncovered strip 0.420 m → 0.0122–0.0131 m**, plus assertions that every course sits on the rib grid, that every run reaches ridge and eave, that no tile lies outside the trapezoid, and that the substrate planes sit below the tile troughs. A new plain-Python **GLB preflight** checks container length, identity node transforms, one mesh / one material / `TEXCOORD_0` per part and per-part triangle counts against the manifest; the landmark validator no longer hardcodes the triangle total but reads the generator's report and checks **each part**, which is what catches a mesh that was never reimported.
