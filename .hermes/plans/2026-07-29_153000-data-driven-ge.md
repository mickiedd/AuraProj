# Data-Driven GameplayEffects: Eliminate All GE UAssets

**Goal:** Replace all Blueprint UAsset GameplayEffects with C++ GE classes + JSON config, making the project fully UAsset-free for GameplayEffects.

**Architecture:** Three layers:
1. C++ GE classes that mirror existing BP GEs (attributes, pickups, buffs)
2. A JSON config file (`Content/Config/GameplayEffects.json`) that describes each GE's modifiers, duration, and SetByCaller tags
3. A runtime loader that parses the JSON and constructs/uses the C++ GE classes

## Plan

### Task 1: Create UAuraAttributeGameplayEffect (C++ GE for attribute init)

**Files:**
- Create: `Plugins/AuraAbilityGraph/Source/AuraAbilityGraph/Public/AuraAttributeGameplayEffect.h`

**What it does:** A C++ GE that reads modifier config at runtime. Constructor sets DurationPolicy. The actual modifiers are configured via a JSON-driven approach: the GE is constructed with a set of (Attribute, SetByCallerTag, Op) tuples that get added as FGameplayModifierInfo entries in the constructor.

Since UGameplayEffect modifiers are set at construction time (in the CDO), and we need different modifier sets for Primary/Secondary/Vital, we create a single generic C++ class that adds SetByCaller modifiers for ALL attributes. Then at application time, only the relevant SetByCaller tags get magnitudes assigned. Unassigned SetByCaller tags default to 0, which is harmless.

**Step 1:** Create the header:

```cpp
// AuraAttributeGameplayEffect.h
#pragma once
#include "CoreMinimal.h"
#include "GameplayEffect.h"
#include "AbilitySystem/AuraAttributeSet.h"
#include "AuraAttributeGameplayEffect.generated.h"

/**
 * C++ GE for attribute initialization. Replaces the BP UAssets:
 *   PrimaryAttributes_SetByCaller, SecondaryAttributes, SecondaryAttributes_Infinite, VitalAttributes.
 *
 * Usage: set DurationPolicy (Instant or Infinite) and add SetByCaller modifiers
 * for each attribute. At spec creation, AssignTagSetByCallerMagnitude fills in values.
 * Unassigned tags default to 0 (harmless).
 */
UCLASS()
class AURAABILITYGRAPH_API UAuraAttributeGameplayEffect : public UGameplayEffect
{
    GENERATED_BODY()
public:
    UAuraAttributeGameplayEffect()
    {
        DurationPolicy = EGameplayEffectDurationType::Instant;

        // Add SetByCaller modifiers for every attribute the AttributeSet defines.
        // At application time, only the relevant tags get magnitudes; the rest stay 0.
        auto& AddMod = [this](FGameplayAttribute Attr, FGameplayTag Tag) {
            FGameplayModifierInfo& Info = Modifiers.AddDefaulted_GetRef();
            Info.Attribute = Attr;
            Info.ModifierOp = EGameplayModOp::Additive;
            FSetByCaller SetByCaller;
            SetByCaller.DataTag = Tag;
            Info.ModifierMagnitude = FGameplayEffectModifierMagnitude(SetByCaller);
        };

        const FAuraGameplayTags& Tags = FAuraGameplayTags::Get();
        // Primary
        AddMod(UAuraAttributeSet::GetStrengthAttribute(), Tags.Attributes_Primary_Strength);
        AddMod(UAuraAttributeSet::GetIntelligenceAttribute(), Tags.Attributes_Primary_Intelligence);
        AddMod(UAuraAttributeSet::GetResilienceAttribute(), Tags.Attributes_Primary_Resilience);
        AddMod(UAuraAttributeSet::GetVigorAttribute(), Tags.Attributes_Primary_Vigor);
        // Secondary
        AddMod(UAuraAttributeSet::GetArmorAttribute(), Tags.Attributes_Secondary_Armor);
        AddMod(UAuraAttributeSet::GetArmorPenetrationAttribute(), Tags.Attributes_Secondary_ArmorPenetration);
        AddMod(UAuraAttributeSet::GetBlockChanceAttribute(), Tags.Attributes_Secondary_BlockChance);
        AddMod(UAuraAttributeSet::GetCriticalHitChanceAttribute(), Tags.Attributes_Secondary_CriticalHitChance);
        AddMod(UAuraAttributeSet::GetCriticalHitDamageAttribute(), Tags.Attributes_Secondary_CriticalHitDamage);
        AddMod(UAuraAttributeSet::GetCriticalHitResistanceAttribute(), Tags.Attributes_Secondary_CriticalHitResistance);
        AddMod(UAuraAttributeSet::GetHealthRegenerationAttribute(), Tags.Attributes_Secondary_HealthRegeneration);
        AddMod(UAuraAttributeSet::GetManaRegenerationAttribute(), Tags.Attributes_Secondary_ManaRegeneration);
        // Vital
        AddMod(UAuraAttributeSet::GetMaxHealthAttribute(), Tags.Attributes_Vital_MaxHealth);
        AddMod(UAuraAttributeSet::GetMaxManaAttribute(), Tags.Attributes_Vital_MaxMana);
        // Resistance
        AddMod(UAuraAttributeSet::GetFireResistanceAttribute(), Tags.Attributes_Resistance_Fire);
        AddMod(UAuraAttributeSet::GetLightningResistanceAttribute(), Tags.Attributes_Resistance_Lightning);
        AddMod(UAuraAttributeSet::GetArcaneResistanceAttribute(), Tags.Attributes_Resistance_Arcane);
        AddMod(UAuraAttributeSet::GetPhysicalResistanceAttribute(), Tags.Attributes_Resistance_Physical);
    }
};
```

Note: The Infinite variant is a separate subclass that just sets DurationPolicy = Infinite in its constructor.

### Task 4: Create UAuraPickupGameplayEffect (C++ GE for AuraEffectActor)

**Files:**
- Create: `Plugins/AuraAbilityGraph/Source/AuraAbilityGraph/Public/AuraPickupGameplayEffect.h`

A generic C++ GE for pickup/buff effects. DurationPolicy is configurable (Instant/Duration/Infinite). Modifiers are SetByCaller — the magnitude values come from the JSON config at runtime.

```cpp
UCLASS()
class AURAABILITYGRAPH_API UAuraPickupGameplayEffect : public UGameplayEffect
{
    GENERATED_BODY()
public:
    UAuraPickupGameplayEffect()
    {
        DurationPolicy = EGameplayEffectDurationType::Instant;
        // Add SetByCaller modifier for Health (potions heal) and Mana (potions restore mana)
        auto& AddMod = [this](FGameplayAttribute Attr, FGameplayTag Tag) {
            FGameplayModifierInfo& Info = Modifiers.AddDefaulted_GetRef();
            Info.Attribute = Attr;
            Info.ModifierOp = EGameplayModOp::Additive;
            FSetByCaller SetByCaller;
            SetByCaller.DataTag = Tag;
            Info.ModifierMagnitude = FGameplayEffectModifierMagnitude(SetByCaller);
        };
        AddMod(UAuraAttributeSet::GetHealthAttribute(), FGameplayTag::RequestGameplayTag(FName("Attributes.Vital.Health"), false));
        AddMod(UAuraAttributeSet::GetManaAttribute(), FGameplayTag::RequestGameplayTag(FName("Attributes.Vital.Mana"), false));
    }
};
```
